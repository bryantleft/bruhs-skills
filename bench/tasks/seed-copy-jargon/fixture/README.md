# tidewatch-site

The tidewatch.dev landing page. Vite + React, static: no backend. Page copy lives in
`src/App.tsx`; plan names, prices and plan bullets in `src/plans.ts`.

```sh
npm install
npm run dev        # http://localhost:5173
npm test           # vitest
npm run typecheck
npm run build      # then `npm run preview` to serve dist/
```
